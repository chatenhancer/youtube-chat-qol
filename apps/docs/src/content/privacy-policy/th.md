# ความเป็นส่วนตัว

อัปเดตล่าสุด: 24 กรกฎาคม 2026

Chat Enhancer for YouTube เป็นส่วนขยายเบราว์เซอร์สำหรับแชทสดของ YouTube ออกแบบมาเพื่อเพิ่มฟีเจอร์แชทเล็ก ๆ โดยไม่แทนที่แชทของ YouTube หรือเก็บข้อมูลวิเคราะห์

สรุปสั้น ๆ:

- ฟีเจอร์ส่วนใหญ่ของส่วนขยายทำงานภายในเบราว์เซอร์ของคุณ
- การแปลปิดอยู่ตามค่าเริ่มต้น
- เมื่อเปิดใช้การแปล ข้อความที่ถูกแปลจะถูกส่งไปยัง Google Translate
- เกม Playground ปิดอยู่ตามค่าเริ่มต้น หากคุณเปิดใช้และใช้ Playground สถานะการเล่นเกม คำเชิญ และการกระทำในเกมจะถูกส่งไปยังเซิร์ฟเวอร์เกม Chat Enhancer Playground ภายใต้ชื่อผู้เล่นที่สร้างขึ้น
- ส่วนขยายไม่เรียกใช้การวิเคราะห์ ไม่ขายข้อมูล และไม่เก็บประวัติการท่องเว็บ

## ส่วนขยายทำงานที่ไหน

ส่วนขยายทำงานเฉพาะบนหน้าแชทสดของ YouTube และหน้า replay แชทสดที่ส่วนขยายได้รับอนุญาตให้เข้าถึง

ส่วนขยายใช้สิทธิ์เพื่อบันทึกการตั้งค่าและข้อมูลของตัวเองในเบราว์เซอร์ของคุณ และยังใช้การเข้าถึงเว็บไซต์เฉพาะที่จำเป็นต่อการทำงานของฟีเจอร์ ได้แก่ หน้าแชทสดของ YouTube, บริการแปลของ Google Translate และเซิร์ฟเวอร์เกม Chat Enhancer Playground แบบเลือกเข้าร่วม

ส่วนขยายไม่ขอสิทธิ์ทั่วไปสำหรับประวัติการท่องเว็บ การอ่านแท็บ scripting หรือ web navigation

## ข้อมูลที่เก็บในเบราว์เซอร์ของคุณ

ส่วนขยายเก็บข้อมูลบางอย่างเพื่อให้ฟีเจอร์ทำงานได้ระหว่างการโหลดหน้าใหม่

เว้นแต่จะระบุไว้เป็นอย่างอื่นด้านล่าง ข้อมูลในส่วนนี้จะอยู่ในโปรไฟล์เบราว์เซอร์ของคุณและไม่ถูกส่งไปยัง Chat Enhancer เบราว์เซอร์อาจซิงค์การตั้งค่าส่วนขยายระหว่างการติดตั้งเบราว์เซอร์ของคุณที่ลงชื่อเข้าใช้ไว้

- **การตั้งค่า:** ตัวเลือกฟีเจอร์และการกำหนดลักษณะของคุณ

- **ข้อมูล Inbox:** คีย์เวิร์ดที่เฝ้าดูและรายการ inbox สูงสุด 100 รายการต่อ stream หรือ replay รายการ Inbox อาจมีข้อความ ชื่อผู้เขียน timestamp, รายละเอียดข้อความ YouTube พื้นฐานที่จำเป็นต่อการแสดงว่าข้อความที่บันทึกไว้มาจากที่ใด, รายละเอียดการจับคู่ และข้อมูล emoji หรือรูปภาพที่จำเป็นต่อการแสดงข้อความที่บันทึกไว้อย่างถูกต้อง

- **ข้อมูล emoji ที่ใช้บ่อย:** จำนวนการใช้งานในเครื่องและข้อมูลการแสดงผล emoji ที่ใช้สร้างแถว emoji ที่ใช้บ่อย

- **ข้อมูลบุ๊กมาร์ก:** ข้อความที่บันทึกและข้อมูลแสดงอีโมจิ ชื่อผู้เขียน URL อวาตาร์และ channel ID เมื่อมี เวลาของข้อความและเวลาที่บันทึก รวมถึงชื่อและ URL ของสตรีม บุ๊กมาร์กยังใช้งานข้ามสตรีมในโปรไฟล์เบราว์เซอร์ปัจจุบันได้

- **ข้อมูลวงแหวนอวาตาร์:** ชื่อผู้เขียน เวลาที่เพิ่มวงแหวน URL ของสตรีม และ URL อวาตาร์ channel ID และชื่อสตรีมเมื่อมี สำหรับผู้ใช้ที่คุณเลือกเพิ่มวงแหวนจากโปรไฟล์ข้อความล่าสุดโดยตรง การเลือกนี้ยังใช้งานข้ามสตรีมในโปรไฟล์เบราว์เซอร์ปัจจุบันได้ และใช้เพื่อตกแต่งอวาตาร์ที่ตรงกันเท่านั้น

- **ร่างแชทที่ยังไม่ได้ส่ง:** เก็บแยกสำหรับแต่ละ stream และกู้คืนหลังรีเฟรชหน้า ร่างจะถูกลบเมื่อช่องแชทถูกล้าง ข้อความถูกส่ง หรือข้อมูลส่วนขยายถูกรีเซ็ต

- **ข้อมูลตัวตน Playground:** ตัวตนในเครื่องที่สร้างแบบสุ่มเมื่อใช้ Playground ใช้เพื่อจำการติดตั้งเบราว์เซอร์เดิมเมื่อเชื่อมต่อกับ Playground อีกครั้ง นี่ไม่ใช่ตัวตน YouTube ของคุณ

- **ข้อมูลหน้าชั่วคราว:** ข้อความโปรไฟล์ล่าสุด สถานะคำสั่ง และผลการแปลถูกเก็บไว้ในหน่วยความจำสำหรับหน้าแชทสดปัจจุบันเท่านั้น และจะถูกล้างเมื่อคุณออกจากหน้าแชทหรือรีเฟรชหน้า

## ข้อมูลที่ส่งออกนอกเบราว์เซอร์ของคุณ

ข้อมูลจะถูกส่งไปยังบริการเหล่านี้เฉพาะเมื่อเปิดใช้และใช้งานฟีเจอร์ที่เกี่ยวข้อง:

### Google Translate (`translate-pa.googleapis.com`)

การแปลแชทส่งข้อความแชทที่มองเห็นในแชทสดและเข้าเกณฑ์สำหรับการแปลในขณะที่เปิดใช้การแปล การแปลร่างส่งข้อความร่างที่คุณเลือกแปลจากกล่องแชท

คำขอแปลมีข้อความที่จะถูกแปลและภาษาปลายทาง ส่วนขยายไม่ส่ง cookies ของ YouTube หรือ credentials ของ YouTube ของคุณไปกับคำขอแปล

การเข้าถึง Google Translate ผ่าน `translate-pa.googleapis.com` เป็นแบบไม่เป็นทางการ และอาจถูกจำกัด เปลี่ยนแปลง หรือไม่พร้อมใช้งาน

### <span id="playground"></span>Chat Enhancer Playground ([playground.chatenhancer.com](https://playground.chatenhancer.com))

หากคุณเปิดใช้ Playground และใช้แผงเกม ส่วนขยายจะเชื่อมต่อกับเซิร์ฟเวอร์เกม Chat Enhancer Playground เพื่อให้ผู้ใช้ที่เลือกเข้าร่วมใน stream เดียวกันเห็นสถานะพร้อมเล่น แลกเปลี่ยนคำเชิญ และเล่นเกมได้

ข้อความ Playground อาจมีตัวระบุ stream หรือ video ของ YouTube, ตัวตนผู้เล่น Playground ที่สร้างขึ้นของคุณ, ชื่อผู้เล่นที่สร้างขึ้นของคุณ, รายการเกมที่คุณพร้อมเล่น, คำเชิญและคำตอบคำเชิญ และการกระทำในเกม เช่น เดินหมากรุก

Playground จัดเก็บผลการแข่งขันแบบย่อที่เชื่อมโยงกับตัวตนผู้เล่น Playground ที่สร้างขึ้น เพื่อให้บริการสถิติผู้เล่น ผลที่จัดเก็บอาจมีเวอร์ชันเกม เวลาเริ่มและสิ้นสุด ผลการแข่งขันและเหตุผลที่จบเกม บทบาทของผู้เข้าร่วม และสถิติเฉพาะเกมขนาดเล็ก เช่น จำนวนการเดินหรือคะแนน โดยไม่รวมเนื้อหาคำถาม trivia หรือสถานะเกมทั้งหมด

ส่วนขยายไม่ส่งข้อความแชทสด ชื่อแสดง YouTube ของคุณ URL avatar YouTube ของคุณ cookies ของ YouTube หรือ credentials ของ YouTube ไปยังเซิร์ฟเวอร์เกม Playground

แยกต่างหาก การสร้างคำถาม HELP-A-FRIEND! Trivia อาจส่งส่วนที่เลือกจาก transcript ของวิดีโอ YouTube สาธารณะและตัวระบุเกมไปยังเซิร์ฟเวอร์เกม Playground ส่วนเหล่านี้มาจาก transcript ของวิดีโอ ไม่ใช่จากแชทสด เซิร์ฟเวอร์ใช้ OpenAI เพื่อสร้างคำถาม trivia จากส่วนเหล่านั้น

การสร้าง Replay Trivia อาจต้องใช้การตรวจสอบ Cloudflare Turnstile ที่ [playground.chatenhancer.com](https://playground.chatenhancer.com) Cloudflare อาจได้รับข้อมูลตรวจสอบทั่วไป เช่น IP address, ข้อมูลเบราว์เซอร์และอุปกรณ์ และผล challenge

เช่นเดียวกับบริการเว็บอื่น เซิร์ฟเวอร์เกม Playground อาจได้รับข้อมูลการเชื่อมต่อทั่วไป เช่น IP address และข้อมูลเบราว์เซอร์/อุปกรณ์ จากเบราว์เซอร์หรือผู้ให้บริการเครือข่าย

## การควบคุมข้อมูล

คุณสามารถล้างข้อมูลส่วนขยายจาก popup ของส่วนขยายโดยใช้ปุ่มรีเซ็ต การดำเนินการนี้จะล้างข้อมูลส่วนขยายในเครื่องและการตั้งค่าส่วนขยายที่ซิงค์ไว้ จากนั้นคืนค่าการตั้งค่าเริ่มต้น

คุณยังสามารถนำส่วนขยายออกจากเบราว์เซอร์ได้ ขึ้นอยู่กับเบราว์เซอร์ การนำส่วนขยายออกอาจลบ storage ในเครื่องของส่วนขยายนั้นด้วย

การรีเซ็ตหรือนำส่วนขยายออกไม่ได้ลบผลการแข่งขันที่ Playground จัดเก็บไว้แล้วโดยอัตโนมัติ

## สิ่งที่ส่วนขยายไม่ทำ

- เรียกใช้การวิเคราะห์
- เก็บประวัติการท่องเว็บ
- ขายข้อมูลผู้ใช้
- ส่งข้อมูลไปยังเซิร์ฟเวอร์ Chat Enhancer เว้นแต่คุณจะใช้ฟีเจอร์ Playground แบบเลือกเข้าร่วมที่อธิบายข้างต้น
