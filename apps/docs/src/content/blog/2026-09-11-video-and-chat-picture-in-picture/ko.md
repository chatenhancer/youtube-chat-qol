웹을 탐색하거나 일하거나 메모하면서도 스트림을 시청하고 대화를 따라가세요. **동영상 + 채팅 PiP**는 YouTube 플레이어와 직접 참여할 수 있는 실시간 채팅을 다른 창 위에 유지되는 하나의 창으로 모아 줍니다.

보기 편한 구석으로 옮기고 계속 시청하세요. YouTube 탭으로 돌아가지 않고도 채팅을 읽고 답할 수 있습니다.

## 채팅 메뉴에서 열기

:::media-left

![가상의 채팅 참여자와 동영상 및 채팅 PiP 옵션을 보여 주는 Chat Enhancer 메뉴](./menu.png) {shadow=smooth}

실시간 채팅이 열린 YouTube 시청 페이지에서 다음과 같이 선택하세요.

1. 채팅 상단의 **더보기**를 엽니다.
2. **Chat Enhancer**를 선택합니다.
3. **동영상 + 채팅 PiP**를 선택합니다.

:::

## 작은 창에 둘 다 담기

창을 열면 간결해진 채팅 위에 동영상이 표시됩니다. 화면에 맞게 크기를 조절하세요. 창을 넓히면 동영상과 채팅이 나란히 배치됩니다.

![동영상과 가상의 실시간 채팅이 나란히 표시되는 넓은 PIP 창.](./pip-wide.png) {shadow=smooth}

:::media-right

![가상 메시지가 있는 채팅 위에 동영상을 배치한 작은 PiP 창](./pip-stacked.png)

### 익숙한 조작 기능을 그대로

일시 중지, 음량 조절, 화질 변경, 다시보기 탐색은 물론, 동영상에서 지원하는 경우 자막도 켤 수 있습니다. YouTube 플레이어의 조작 기능은 동영상과 함께, Chat Enhancer 도구는 채팅과 함께 유지됩니다.

플로팅 창에서는 채팅 간격이 더 촘촘해집니다. 평소 사용하던 채팅 밀도 설정은 저장되어 있으며 탭으로 돌아오면 다시 적용됩니다.

:::

## 한 번의 클릭으로 탭으로 돌아가기

플로팅 창을 닫거나 원래 동영상 또는 채팅 영역에서 **탭으로 돌아가기**를 선택하세요. 둘 다 YouTube의 원래 위치로 돌아가고, 보내지 않은 채팅 초안도 함께 유지됩니다.

PiP를 사용하는 동안에는 원래 YouTube 탭을 열어 두세요. 스트림을 떠나면 플로팅 세션이 종료됩니다.

## 지원 브라우저

동영상 + 채팅 PiP는 지원되는 데스크톱 버전의 **Chrome, Edge, Firefox**에서 사용할 수 있습니다. Safari는 현재 동영상과 채팅을 결합한 이 창을 지원하지 않으므로 해당 옵션이 숨겨집니다.
